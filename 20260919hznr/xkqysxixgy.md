# 孕妇高血糖可以吃紫薯吗

> 更新时间：2026-09-19 (UTC+8)

紫薯是生活中常见的主食，不仅仅含有很多的纤维素，还含有丰富的蛋白质氨基酸，紫薯极易被人体消化吸收，常吃紫薯可以缓解便秘，增强免疫力。女性在怀孕的时候，饮食需要非常的注意，那么，孕妇高血糖可以吃紫薯吗?
孕妇高血糖可以吃紫薯吗
　　1.怀孕妇女可适当吃些紫薯。紫薯含有丰富的蛋白质、淀粉、纤维素、维他命及多种微量元素,既能为孕妇提供最基本的营养物质和能量,又能起到防老、抗疲劳、补血、提高免疫力等作用,因此孕妇是可以食用的。

　　2.　血糖高可以吃紫薯，但是不能多吃。紫薯的主要的成分是蛋白质和淀粉，另外还富含纤维素、维生素、矿物质等多种物质，紫薯的营养价值极高。可以有效的抗癌，对于肥胖的人群还有减肥的功效。紫薯不仅能够食用，做食品加工，还可以作为工业原材料。有于淀粉含量高所以，血糖高的情况下，不能多吃。

　　3.紫薯是杂粮类，淀粉含量比较高，和地瓜、芋头、南瓜等食物非常相似。孕妇血糖高可以适当吃紫薯，紫薯要做主食来吃，每顿饭吃一个，其他主食不要吃，多吃蔬菜、肉类食物，对血糖不会有太多影响。如果主食吃紫薯以后，还吃其他主食，比如米饭、馒头等，会导致餐后血糖偏高，是淀粉含量比较高的食物。

　　4.孕妇在怀孕期间如果有高血糖的情况的话，一定要控制自己的饮食情况，建议让比较专业的人士来安排饮食。
紫薯的作用功效有哪些
　　1.防癌抗癌、抗氧化、抗突变，紫薯富含硒和铁是人体抗疲劳、抗衰老、补血的必要元素，特别是硒被称为“抗癌大王”,易被人体吸收，可留在血清中，修补心肌，增强机体免疫力，清除体内自由基，抑制癌细胞中DNA的合成和癌细胞的分裂与生长，预防胃癌、肝癌等癌病的发生。

　　2.促进胃肠蠕动，紫薯富含纤维素，可促进胃肠蠕动，清理肠腔内滞留的粘液、积气和腐败物，排除粪便中的有毒物质，保持大便通畅，改善消化道的环境，防止胃肠道疾病的发生。

　　3.增强免疫力，紫薯含有大量黏液蛋白，能够防止肝脏和肾脏结缔组织萎缩，提高机体免疫力。紫薯中所含有矿物质对于维持和调节人体功能，起着十分重要的作用。

　　4.对心血管病作用，花色苷有减少心血管病作用，在体外实验中，花色苷能明显抑制低密度脂蛋白氧化和血小板的聚集，而这两种物质是引发动脉粥样硬化的主要原因。
